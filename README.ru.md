# Oxill Read Book

**Русский** | [English](README.md)

Настольная читалка EPUB, FB2 и PDF для Obsidian. Плагин объединяет библиотеку,
чтение, выделения, цитаты, заметки книг, серии и локальную аналитику в одном
интерфейсе.

> Плагин работает только в настольной версии Obsidian.

## Возможности

- чтение EPUB, FB2 и PDF без отправки книг во внешние сервисы;
- библиотека с обложками, поиском, категориями и статусами чтения;
- отдельное представление серий с порядком книг, категориями и обложками;
- постраничный режим и прокрутка, оглавление и полнотекстовый поиск;
- цветные выделения, комментарии и ссылки на точное место в книге;
- экспорт цитат в заметку книги или отдельные заметки по шаблону;
- группировка экспортированных цитат по заголовкам книги;
- создание, выбор и открытие заметки книги прямо из читалки;
- именованные ручные точки и одно перезаписываемое автосохранение;
- сворачиваемый таймер чтения с паузой, сбросом и локальными звуками;
- статистика чтения и календарь активности в стиле GitHub;
- необязательная интеграция с List Callouts;
- русский и английский интерфейс.

## Установка

### Вручную

1. Откройте каталог вашего хранилища Obsidian.
2. Создайте папку `.obsidian/plugins/oxill-read-book`.
3. Скопируйте в неё файлы релиза:
   - `main.js`;
   - `manifest.json`;
   - `styles.css`;
   - папку `assets`;
   - папку `sounds`.
4. Перезапустите Obsidian или перезагрузите плагины.
5. Включите **Oxill Read Book** в разделе «Сторонние плагины».

## Начало работы

Откройте палитру команд Obsidian и выполните команду
**«Oxill Read Book: Открыть библиотеку»**. Книги можно добавить перетаскиванием
в библиотеку либо положить в настроенную папку книг.

Настройки конкретной книги доступны через панель читалки. Глобальные параметры
чтения, заметок, оформления, коннекторов и хранения данных находятся в
настройках плагина.

## Отличия от Elton Reader

Oxill Read Book создан на основе
[Elton Reader](https://github.com/swayinfo/elton-reader), но развивает другой
настольный сценарий работы:

- полностью исключена мобильная версия и связанные с ней элементы интерфейса;
- библиотека получила режим серий, категории серий, порядок книг и обложки;
- заметки книг хранят категории, серию и номер книги;
- переработана система цитат: синхронизация удалений, наследование заголовков,
  переход к выделению и отдельные шаблоны для конкретных книг;
- добавлен коннектор List Callouts с сопоставлением цветов и символов;
- переработаны точки сохранения и добавлено перезаписываемое автосохранение;
- таймер получил компактную панель, ручное скрытие, сброс и локальные звуки;
- добавлен раздел аналитики с показателями чтения и календарём активности;
- переработаны библиотека, настройки, контекстные меню и управление обложками;
- удалены функции перевода и AI, а данные чтения остаются локальными.

Это самостоятельная переработка, а не официальная версия Elton Reader.

## Сборка из исходников

Требуются Node.js и npm.

```bash
npm install
npm run build
```

Основной исходный код хранится в одном файле `src/main.js`. Итоговый `main.js`
включает PDF.js worker и готов для загрузки Obsidian.

Проверка кода:

```bash
npx eslint src/main.js
```

## Конфиденциальность

Книги, прогресс, выделения, заметки и аналитика обрабатываются локально. Плагин
не требует аккаунта и не содержит телеметрии. Необязательная интеграция с List
Callouts также работает локально.
