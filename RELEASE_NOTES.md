# Oxill Read Book 1.0.0

Первый публичный выпуск настольной читалки для Obsidian.

## Основное

- чтение EPUB, FB2 и PDF;
- библиотека книг и серий с поиском, фильтрами и обложками;
- выделения, комментарии, цитаты и ссылки на точное место в книге;
- заметки книг с категориями, сериями и шаблонами цитат;
- ручные и автоматические точки сохранения;
- таймер чтения со звуками и компактным режимом;
- аналитика чтения с календарём активности;
- опциональная интеграция с List Callouts;
- полностью локальная работа без телеметрии;
- поддержка только настольной версии Obsidian.

Проект основан на [Elton Reader](https://github.com/swayinfo/elton-reader) и
распространяется по лицензии MIT.
